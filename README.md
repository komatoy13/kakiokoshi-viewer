# 書き起こし一覧 ＆ 統合年表（閲覧専用ビューア）

「御書データベース＆統合年表」アプリで登録した内容を、編集はできない形で他の方に見てもらうための、別の軽いWebサイトです。

- 「書き起こし」（統合年表・一覧の2モードを切り替え）／AI解説（用語辞典）／人物データベース／結合した御書／横断検索の5つを、見る・検索するだけの画面で提供します。「結合した御書」では、御書ごとに結合した文面と、元になった御文（講義録などの御文・解説書の御文）の出典を見られます。
- 「書き起こし」タブは、開くとまず年表モードが表示されます。右下の「▲上へ」ボタンの上にある丸いボタンで、一覧モードに切り替えられます。
- 保存・削除・追加のボタンや、取り込み・設定の画面はそもそも存在しません。
- データは、編集用アプリから公開した「公開Gist」を毎回読みに行くので、**編集用アプリ側で「保存して公開ビューアにも反映」ボタンを押すだけで、ビューアも自動的に最新の内容になります**（ビューア自体を作り直したり、再度公開したりする必要はありません）。

## 初めての設定（最初の1回だけ）

1. 編集用アプリの「設定・人物データ編集」タブ →「公開ビューアへの反映」→「初めて公開する（新規作成）」を押します。
2. 表示されたGist ID（例：`a1b2c3d4e5...`）を控えます。
3. このフォルダの `js/viewer.js` を開き、冒頭付近の

   ```js
   const DEFAULT_GIST_ID = 'ここに公開用のGist IDを入力してください';
   ```

   の `'ここに公開用のGist IDを入力してください'` の部分を、控えたGist IDに書き換えて保存します。
4. このフォルダ一式（`index.html` / `css` / `js`）を、GitHubの新しいリポジトリ（例：`kakiokoshi-viewer`）にアップロードし、GitHub Pagesを有効にします。

以降は、編集用アプリで御書を追加・修正するたびに、「保存して公開ビューアにも反映」ボタンを押すだけで、このビューアの内容も更新されます。ビューア側のファイルを再度アップロードする必要はありません。

### Gist IDを書き換えずに使う方法

`js/viewer.js` を編集しなくても、共有するリンクの末尾に `?gist=あなたのGistID` を付ければ、そのリンクを開いた人にはそのGistの内容が表示されます（例：`https://（あなたのGitHub名）.github.io/kakiokoshi-viewer/?gist=a1b2c3d4e5`）。ただし、リンクが長くなるため、通常は上の方法（`DEFAULT_GIST_ID` の書き換え）をおすすめします。

## ファイル構成

```
kakiokoshi-viewer/
├── index.html       ← ビューアの画面
├── css/styles.css    ← 編集用アプリと共通のデザイン
└── js/
    ├── db.js          ← 編集用アプリと共通（データの型・表示用の関数など）
    ├── eras.js        ← 編集用アプリと共通（時代区分の判定）
    ├── timeline.js    ← 編集用アプリと共通（年表・書き起こし一覧の描画）
    ├── render.js      ← 編集用アプリと共通（本文の整形・ルビ表示・PDF出力）
    ├── search.js      ← 編集用アプリと共通（横断検索）
    ├── ai-notes.js    ← ビューア専用の短縮版（AI解説の一覧表示の部分のみ）
    └── viewer.js      ← ビューア専用（データ取得・タブ切り替え・閲覧専用への調整）
```

`db.js`・`eras.js`・`timeline.js`・`render.js`・`search.js` は編集用アプリと全く同じファイルです（画面に保存・削除ボタンが無いため、編集用の関数は実際には使われません）。`ai-notes.js` と `viewer.js` はビューア専用のファイルです。`ai-notes.js` は、編集用アプリの同名ファイルのうち「AI解説の一覧表示」の部分だけを残した短縮版で、人物データの編集や、表記ゆれの統合候補などの編集用の機能は入っていません。`viewer.js` は、公開Gistからのデータ取得（ルビ範囲辞書を含む設定の読み込みを含む）と、「詳細を見る」等の遷移先を編集フォームではなく閲覧用のポップアップに差し替える処理を行っています。

編集用アプリ側を改修した際は、`db.js`・`eras.js`・`timeline.js`・`render.js`・`search.js` の5つをこのフォルダにも上書きコピーしてください（`ai-notes.js` と `viewer.js` は上書きしないでください。`viewer.js` には公開用のGist IDが入っています）。

## 更新履歴

- 全文表示の画面に「ふりがな」の選択を追加：ルビ（漢字の上に小さく）／括弧書き（寂光(じゃっこう)）。PDF出力にも反映されます。選択はその端末に記憶されます。
- ルビの範囲の判定を改善：編集アプリの「ルビ範囲辞書」（公開時に一緒に届きます）や、本文中の「｜」の目印、同じ本文内の根拠から、「皆寂光(じゃっこう)」のような箇所で「寂光」だけにルビを付けます。
- 閏月（例：閏十月）の「閏」を、年表の和暦表示に反映。
- ルビ（ふりがな）の表示に対応：本文・御文の「漢字(よみ)」を、画面上で本物のルビに組み直して表示します。
- 閏月（例：閏十月）の和暦の読み取りに対応。
- 御書マスタとの照合処理の更新（編集用アプリ側の年表連携の改修に追随）。
